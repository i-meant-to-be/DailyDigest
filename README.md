# DailyDigest

기술 면접 대비 CS 지식 점검 저장소. 지식을 쌓아 두는 곳이자, 그 지식을 실제로 설명할 수 있는지 매일 점검하는 도구다.

## 무엇을 하는가

문항 하나하나에 대해 **내가 지금 이걸 말로 설명할 수 있는가**를 기록한다. 다이제스트를 돌릴 때마다 이 기록을 근거로 문제가 뽑히고, 채점 결과가 다시 기록에 반영된다. 아는 것은 뜸하게, 틀린 것은 자주, 아예 모르는 것은 새로 발굴해서 물어본다.

## 사용법

저장소 루트에서 Claude Code 또는 Codex를 실행한 뒤:

```
/digest
```

1. **출제** — 현재 상태를 읽고 정책대로 문항을 골라 질문지를 만든다. 경로를 알려 준다.
2. **답변** — 그 질문지 파일의 `### 내 답변` 아래에 직접 답을 적는다. 참고 자료를 보지 말 것. 면접장에서 말할 수 있는 만큼만 적는다.
3. **채점** — 다시 `/digest`를 실행하면 답변을 채점하고, 맞고 틀린 이유를 설명하고, 상태를 갱신한다.

### 그 밖의 명령

| 명령 | 하는 일 |
| --- | --- |
| `/digest` | 미채점 질문지가 있으면 채점, 없으면 새 출제 |
| `/digest new [문항수]` | 새 질문지를 강제로 생성 |
| `/digest grade [세션 id]` | 특정 질문지를 채점 |
| `/digest status` | 현재 숙련도 리포트를 갱신하고 요약을 출력 |

## 저장소 구조

| 경로 | 내용 |
| --- | --- |
| `knowledge/` | 지식 원본. 문항마다 고정 ID와 난이도를 가진다 |
| `knowledge/SYLLABUS.md` | 주제 대장. 다뤄야 할 주제 목록과 문항 ID 매핑 |
| `state/mastery.json` | 문항별 이해 상태 (원본, 스크립트만 수정) |
| `state/REPORT.md` | 과목별·난이도별 숙련도 리포트 (자동 생성) |
| `sessions/` | 질문지와 채점 결과 |
| `scripts/digest.mjs` | 선정·상태 전이·집계를 담당하는 스크립트 |
| `docs/AUDIT.md` | 지식 원문의 정합성 진단과 수정 승인 대장 |
| `PROFILE.md` | 목표 직무와 배경. 출제 눈높이의 기준 |

## 원칙

- **지식 원문은 사용자의 것이다.** 이 저장소를 운용하는 AI 에이전트(Claude, Codex 등)는 오류를 발견해도 `docs/AUDIT.md`에 제안으로 올릴 뿐, 승인 없이 고치지 않는다.
- **상태는 채점 결과에만 근거한다.** 대화 중의 인상으로 바뀌지 않는다.
- **채점은 면접관 기준이다.** 좋게 봐주지 않는다.
